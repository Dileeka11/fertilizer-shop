I have created two filles in admin folder to test.
	admin/switch-role.php
	admin/admin/test-roles.php




Following codes are used to run it,




1) switch-role.php

<?php
session_start();
if (isset($_POST['role'])) {
    $_SESSION['admin_role'] = $_POST['role'];
    // Redirect back to the page you came from, or to a default
    $redirect = $_POST['redirect'] ?? '/fertilizer-shop/admin/index.php';
    header('Location: ' . $redirect);
    exit;
}
// If accessed directly, show a simple message
echo 'Use this page only via POST.';
